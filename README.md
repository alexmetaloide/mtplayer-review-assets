# mtplayer evaluation media

This folder prepares a separate, no-login playlist for Samsung application reviewers. It contains no mtplayer source code or private customer playlists. The app remains an empty player until a reviewer imports the playlist.

## Reviewer instructions

Playlist URL: https://raw.githubusercontent.com/alexmetaloide/mtplayer-review-assets/main/review-playlist.m3u

1. Select **Adicionar playlist** (Add playlist), then **M3U**.
2. Enter any playlist name and paste the URL above into **URL da playlist**.
3. Select **Salvar e carregar** (Save and load).
4. Select **Filmes** (Movies), then **Big Buck Bunny - Blender Foundation** or **Abrir agora** (Open now).
5. During playback, OK toggles pause, left/right seek by 15 seconds, and Return exits playback.

No username, password, voucher, subscription or mtplayer activation is required for this playlist.
Movie download: https://github.com/alexmetaloide/mtplayer-review-assets/releases/download/v1/BigBuckBunny.mp4

## Scope and limitations

This is a prerecorded movie test, not a live television channel or a subscription. It does not verify Xtream authentication, episodic catalogs, DRM, live broadcasting or physical Samsung TV compatibility. Network availability and the final public playlist URL must be checked before submission.
